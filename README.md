# 🧠 ERO — Neural Network From Scratch

A core Python implementation of a neural network built completely from scratch without using any external machine learning libraries. This project focuses on understanding the internal mechanics and mathematics behind neural networks.

---

## 📌 Overview

ERO is a deep dive into AI fundamentals, where every component of a neural network is manually implemented using pure Python. The project demonstrates a strong understanding of how neural networks function internally, including forward propagation, backpropagation, and optimization.

---

## ✨ Features

* 🧠 Custom-built neural network architecture
* 🔁 Forward propagation implementation
* 📉 Loss calculation mechanisms
* 🔄 Backpropagation algorithm from scratch
* ⚙️ Gradient descent optimization for weight updates
* 📊 Mathematical understanding of AI models
